> **기록되지 않은 구역을 감시하고, 화면 속 이상을 찾아 보고하라.**  
> 《미기록 구역》은 CCTV 화면의 미세한 변화를 판별하고 제한 시간 동안 근무를 완수하는 2D 관찰형 공포 게임입니다.

## 게임 개요

플레이어는 폐쇄된 시설의 야간 감시 요원이 되어 여러 CCTV 채널을 순찰합니다. 평소의 배치를 기억하고, 물체의 이동·사라짐·형태 손상·인물의 비정상 행동처럼 **기준 화면과 달라진 현상**을 발견해야 합니다.

이상현상을 찾으면 보고판에서 **장소 → 대상 → 현상**을 선택해 보고합니다. 보고가 늦거나 잘못되면 시설의 상황이 점차 악화되며, 정전과 현장 이동 등 CCTV 밖의 사건에도 직접 대응해야 합니다.

### 목표와 종료 조건

- 제한 시간 동안 이상현상을 찾아 정확히 보고하고 근무를 끝내세요.
- 정전이나 외부 사건이 발생하면 메인룸의 안내에 따라 현장 문제를 해결하세요.
- 오보고와 미보고가 누적되면 해당 일차의 근무에 실패합니다.
- 근무를 마치면 다음 날짜가 해금되며, 날짜가 지날수록 새로운 공간·인물·현상이 추가됩니다.

## 플레이 흐름

1. **메인룸**에서 전화를 받아 그날의 업무를 확인합니다.
2. CCTV를 클릭해 **감시 화면**으로 진입합니다.
3. 화면을 좌우로 살피고 채널을 바꾸며 정상 배치를 기억합니다.
4. 이상을 발견하면 보고판을 열어 **장소·대상·현상**을 선택하고 제출합니다.
5. 정전 또는 외부 사건이 발생하면 CCTV에서 나와 현장으로 이동해 상호작용합니다.
6. 문제를 해결한 뒤 감시 업무로 복귀하고, 제한 시간까지 버티면 하루가 종료됩니다.

## 조작 방법

| 입력 | 기능 |
| --- | --- |
| **마우스 클릭** | 메인룸 오브젝트·버튼 선택, 대사 진행 |
| **A / D** 또는 **← / →** | CCTV 화면 좌우 이동, 현장 캐릭터 이동 |
| **Q / E** | 이전·다음 CCTV 채널로 전환 |
| **W** | 이상현상 보고판 열기 / 닫기 |
| **Z** | CCTV 감시 화면에서 메인룸으로 나가기 |
| **E / E 길게 누르기** | 문, 배전반, 기록물 등 현장 오브젝트 상호작용 |
| **Esc** | 일시정지 메뉴 열기 / 현재 팝업 닫기 |

## 이상현상 보고 방법

1. CCTV에서 기준 상태와 달라진 부분을 찾습니다.
2. **W**를 눌러 보고판을 엽니다.
3. 현상이 발생한 **장소**, 달라진 **대상**, 변화의 **종류**를 차례로 선택합니다.
4. 표시된 문장을 확인한 뒤 **보고하기**를 누릅니다.

> 보고판에 보이는 이름이 같은 물체가 여러 개라면, 어느 개체에서 발생했는지와 관계없이 해당 대상 이름을 선택하면 됩니다.

## 실행 방법

별도 설치가 필요하지 않은 **WebGL 웹 빌드**로 실행합니다.

### [웹 빌드 바로 실행](https://play.unity.com/en/games/1047f6b1-3032-47a1-afe2-21e6e1f6b025/6646riw66gdioq1royxrq)

1. 위의 **웹 빌드 바로 실행** 링크에 접속합니다.
2. 로딩이 끝나면 게임 화면을 한 번 클릭합니다.
3. 제목 화면의 안내에 따라 아무 곳이나 클릭해 게임을 시작합니다.
4. 키 입력이 반응하지 않으면 게임 화면을 다시 한 번 클릭해 포커스를 맞춥니다.

### 권장 환경

- PC용 최신 **Chrome** 또는 **Microsoft Edge**
- 키보드와 마우스
- 1920 × 1080 해상도 또는 전체 화면
- 사운드 연출이 중요한 게임이므로 이어폰·헤드폰 사용 권장

## 플레이 팁

- 새 채널에 들어가면 가구, 조명, 문, 인물의 위치를 먼저 확인하세요.
- 큰 변화뿐 아니라 각도, 색, 작은 소품의 추가·제거도 이상현상일 수 있습니다.
- 불확실할 때 무작정 보고하면 오보고가 누적됩니다.
- 화면 노이즈와 경고 문구는 상황 악화의 신호입니다. 다음 행동 안내를 확인하세요.
