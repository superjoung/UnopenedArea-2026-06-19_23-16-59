제출 항목: 사전 과제 5. 팀원 롤 기술서

## 1. 팀 구성 및 역할 요약

| 팀원 | 공식 역할 | 핵심 담당 범위 |
|---|---|---|
| 정회륜 | 팀장 / 기획 / 개발 | 프로젝트 방향과 기획 기준 수립, 초기 게임 로직 및 공용 구조 구현, 3일차 콘텐츠 구현 |
| 장조성 | 개발 | 연출 구체화, 시스템 구현, 1·2일차 플레이 루프와 이상현상 제어 로직 구현, 사운드 적용, 저장·불러오기·다시하기 구현 |

## 2. 팀원별 실제 구현 영역

### 정회륜 - 팀장 / 기획 / 개발자

- 게임의 핵심 콘셉트, 일차별 진행 방향, 이상현상 및 현장 이벤트의 기획 기준을 정리했다.
- 팀의 작업 우선순위와 구현 범위를 조율하고, 기획 변경이 시스템 구조에 반영되도록 의사결정을 담당했다.
- CCTV 감시와 보고를 중심으로 한 초기 게임 로직 및 공용 실행 구조를 구현했다.
- 앞선 일차의 공용 구조를 바탕으로 3일차 전용 콘텐츠와 진행 로직을 구현했다.
- 팀장으로서 기능·아트 결과물을 종합해 프로젝트의 일관성과 제출 방향을 관리했다.

### 장조성 - 개발자

- 기획 문서의 요구 사항을 실제 플레이 가능한 연출과 시스템 단위로 구체화했다.
- 1일차와 2일차의 타이틀, 전화, 대사, CCTV 감시, 보고, 미보고, 정전·현장 이동, 성공·실패 및 다음 일차 전환 흐름을 구현했다.
- 이상현상 데이터를 실제 프리팹 오브젝트에 연결하고, 발생·보고 판정·미보고·정상화·재등장 제어 로직을 구현했다.
- 일차별 특수 연출, 화면 전환, 카메라 및 입력 잠금, UI 상태 연동 등 플레이 흐름의 세부 연출을 구현했다.
- 배경음·효과음 재생 구조와 상황별 사운드를 적용하고, 일시정지 화면의 음량 제어 기반을 구성했다.
- 일차 진행 저장, 해금 상태, 불러오기, 다시하기 및 전체 초기화 등 반복 플레이에 필요한 상태 관리 기능을 구현했다.
- 구현 내용과 Inspector 설정법, 검증 항목을 인수인계 문서로 정리해 다른 개발자가 이어서 작업할 수 있도록 했다.

### 윤보녕 - 아트 담당

- 게임의 배경, 캐릭터, 오브젝트, 이상현상 표현 등 플레이 화면을 구성하는 시각 자산을 제작하고 수정했다.
- 개발 중인 기능과 연출을 실제 화면으로 확인하면서 가시성, 크기, 배치, 분위기와 같은 시각적 문제를 보완했다.
- 개발자와 지속적으로 대화하며 필요한 에셋의 용도와 상태 변형을 확인하고, 정상 상태와 이상현상 상태가 구분되도록 자산을 제공했다.
- 구현 결과에서 발생한 시인성 또는 연출 문제를 공유받아 반복 수정하며 게임의 시각적 통일성과 공포 분위기 형성에 기여했다.

## 3. 개발자 간 AI 기반 인수인계 방식

두 개발자는 서로의 작업을 단순히 구두로 전달하지 않고, AI를 활용해 현재 구조와 변경 사항을 인수인계 문서 및 재사용 가능한 프롬프트 형태로 정리했다.

1. 담당 개발자가 구현 범위, 변경 파일, 데이터 연결, Inspector 설정, 미완료 항목과 테스트 절차를 문서화했다.
2. AI가 긴 작업 기록을 구조화하고, 다음 개발자가 바로 사용할 수 있는 작업 지시 프롬프트로 변환했다.
3. 다음 개발자는 인수인계 문서와 실제 프로젝트 파일을 함께 확인한 뒤 AI에 전달해 구조를 빠르게 재분석했다.
4. AI가 제안한 수정 사항은 개발자가 코드, Unity Inspector와 플레이 결과를 직접 검토한 뒤 반영했다.
5. 완료된 작업은 Git 커밋과 병합 단위로 정리하고, 다음 작업자가 재현할 수 있도록 문서를 갱신했다.

이 방식으로 1·2일차 구현 담당과 3일차 구현 담당 사이에 공용 구조, 일차별 차이, 데이터 ID, 테스트 방법을 빠르게 공유했다. AI는 정보 정리와 분석을 지원했으며, 최종 기획 판단, 코드 반영, 에셋 제작과 플레이 검증은 각 담당 팀원이 수행했다.

## 4. 아트 협업 방식

아트 작업은 문서 전달만으로 끝내지 않고 개발자와 아트 담당자가 계속 대화하며 반복적으로 맞추는 방식으로 진행했다.

- 개발자는 필요한 오브젝트, 정상·이상 상태, 애니메이션 여부와 실제 화면에서의 사용 위치를 설명했다.
- 아트 담당자는 해당 요구에 맞춰 자산을 제작하고, 개발자는 Unity에 배치해 실제 CCTV 화면과 현장 화면에서 확인했다.
- 화면에서 크기, 밝기, 실루엣, 배경과의 구분이 부족한 경우 캡처와 구체적인 피드백을 공유해 수정했다.
- 기능 변경으로 새로운 상태나 연출이 필요하면 개발자가 요구 사항을 다시 전달하고, 아트 담당자가 수정본을 제공하는 반복 구조를 유지했다.

이를 통해 기능 구현과 시각 자산 제작을 분리하면서도, 최종 결과는 실제 플레이 화면을 기준으로 함께 조정했다.

## 7. 최종 역할 원칙

- 정회륜은 팀장으로서 기획과 프로젝트 전체 방향을 책임지고, 초기 구조와 3일차 구현을 담당했다.
- 장조성은 1·2일차의 시스템·콘텐츠 구현과 연출 구체화, 이상현상 제어, 사운드 및 상태 저장·복구를 담당했다.
- 윤보녕은 게임의 시각 자산 제작과 반복 수정을 담당했다.
- 개발자 간에는 AI로 구조화한 인수인계 문서와 프롬프트를 사용해 작업 연속성을 확보했다.
- 개발과 아트 사이에는 지속적인 대화와 플레이 화면 기반 피드백을 통해 기능과 시각 결과물을 통합했다.
- AI는 분석, 문서화, 구현 보조 도구로 활용했으며 최종 결정과 결과물의 책임은 각 담당 팀원에게 있다.
